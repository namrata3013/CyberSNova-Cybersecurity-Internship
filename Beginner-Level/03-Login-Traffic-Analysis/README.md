# Login Traffic Analysis

## Overview

This project focuses on analyzing network traffic associated with login activity to understand how authentication-related communication can be observed and investigated.

## Objectives

- Capture and analyze login-related network traffic
- Examine communication between client and server
- Identify relevant authentication traffic
- Analyze packet-level information
- Document security observations

## Tools Used

- Kali Linux
- Wireshark
- Browser
- Network analysis techniques

## Key Activities

- Network traffic capture
- Packet inspection
- Analysis of login-related requests and responses
- Identification of relevant network communication
- Documentation of findings

## Evidence

The complete technical report containing the methodology, analysis, findings, and screenshots is included in this folder.

## Learning Outcome

This project strengthened my understanding of packet analysis, authentication traffic, network communication, and security monitoring.

## Disclaimer

All testing was performed in authorized training environments for educational purposes.
