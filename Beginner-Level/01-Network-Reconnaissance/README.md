# Network Reconnaissance & Service Enumeration

## Overview

This project focuses on network reconnaissance and service enumeration techniques used to identify hosts, open ports, running services, and available network information.

## Objectives

- Identify active hosts
- Discover open ports
- Enumerate running services
- Analyze collected network information
- Document reconnaissance findings

## Tools Used

- Nmap
- Linux/Kali Linux
- Network reconnaissance techniques

## Key Activities

- Host discovery
- Port scanning
- Service detection
- Enumeration and analysis of discovered services
- Documentation of findings

## Evidence

The complete technical report containing the methodology, findings, commands, and screenshots is included in this folder.

## Learning Outcome

This project strengthened my understanding of network reconnaissance, port scanning, service enumeration, and security assessment methodology.

## Disclaimer

All testing was performed in authorized training environments for educational purposes.
