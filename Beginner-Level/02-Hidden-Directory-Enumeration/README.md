# Hidden Directory & File Enumeration

## Overview

This project focuses on identifying hidden web directories and files that may expose resources or functionality not directly visible through normal website navigation.

## Objectives

- Discover hidden directories and files
- Perform web enumeration
- Identify potentially exposed resources
- Analyze enumeration results
- Document security observations

## Tools Used

- Kali Linux
- Web enumeration tools
- Browser
- Command-line utilities

## Key Activities

- Web directory enumeration
- Identification of accessible resources
- Analysis of discovered paths
- Documentation of findings and observations

## Evidence

The complete technical report containing the methodology, findings, commands, and screenshots is included in this folder.

## Learning Outcome

This project strengthened my understanding of web reconnaissance, directory enumeration, information exposure, and web security assessment.

## Disclaimer

All testing was performed in authorized training environments for educational purposes.
