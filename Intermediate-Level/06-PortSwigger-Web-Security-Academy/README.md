# PortSwigger Web Security Academy Labs

## Overview

This project involved completing practical web security labs from PortSwigger Web Security Academy to develop hands-on skills in identifying and exploiting common web application vulnerabilities in authorized training environments.

## Objectives

- Understand common web application vulnerabilities
- Practice vulnerability identification and exploitation
- Analyze HTTP requests and responses
- Document exploitation techniques
- Understand appropriate security controls and mitigations

## Vulnerabilities Covered

- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Access Control
- File Path Traversal

## Tools Used

- Burp Suite Community Edition
- Web Browser
- PortSwigger Web Security Academy
- Kali Linux

## Methodology

Each lab involved understanding the vulnerability, analyzing application behavior, identifying the relevant attack vector, performing controlled exploitation, and documenting the results and defensive measures.

## Evidence

The complete technical report containing lab descriptions, exploitation steps, screenshots, and completion evidence is included in this folder.

## Learning Outcome

This project strengthened my practical understanding of web application security, HTTP traffic analysis, Burp Suite, vulnerability exploitation, and security testing methodology.

## Disclaimer

All testing was performed within PortSwigger Web Security Academy's authorized training labs for educational purposes.
