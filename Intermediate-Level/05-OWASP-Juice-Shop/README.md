# OWASP Juice Shop Security Assessment

## Overview

This project involved performing a security assessment of OWASP Juice Shop, an intentionally vulnerable web application designed for security training and hands-on vulnerability testing.

## Objectives

- Identify and analyze web application vulnerabilities
- Demonstrate exploitation in an authorized training environment
- Document security findings and their potential impact
- Provide appropriate remediation recommendations

## Vulnerabilities Investigated

- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Access Control
- Sensitive Information Exposure
- Security Misconfiguration

## Tools Used

- OWASP Juice Shop
- Burp Suite Community Edition
- Web Browser
- Kali Linux
- Browser Developer Tools

## Methodology

The assessment involved reconnaissance, vulnerability identification, controlled exploitation, evidence collection, impact analysis, and documentation of remediation measures.

## Evidence

The complete technical assessment report, including exploitation evidence, screenshots, observations, impact, and mitigation recommendations, is included in this folder.

## Learning Outcome

This project strengthened my practical understanding of web application vulnerabilities, HTTP requests and responses, security testing methodology, and vulnerability reporting.

## Disclaimer

Testing was performed against an intentionally vulnerable application in an authorized training environment for educational purposes.
