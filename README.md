# CyberSNova Cybersecurity Internship

This repository contains the practical cybersecurity projects and security assessments completed during my CyberSNova Cybersecurity Internship.

## Internship Projects

### Beginner Level

1. **Network Reconnaissance & Service Enumeration**
   - Host and service discovery
   - Network reconnaissance
   - Service enumeration

2. **Hidden Directory & File Enumeration**
   - Web directory enumeration
   - Identification of potentially exposed resources
   - Web reconnaissance

3. **Login Traffic Analysis**
   - Network traffic analysis
   - Login-related traffic investigation
   - Packet capture analysis

4. **Basic Web Vulnerability Assessment**
   - Web application assessment
   - Identification of common security weaknesses
   - Security findings and remediation recommendations

### Intermediate Level

5. **OWASP Juice Shop Security Assessment**
   - SQL Injection
   - Cross-Site Scripting (XSS)
   - Broken Access Control
   - Sensitive information exposure
   - Security misconfiguration

6. **PortSwigger Web Security Academy Labs**
   - SQL Injection
   - Cross-Site Scripting (XSS)
   - Broken Access Control
   - File Path Traversal
   - Web application security testing
